# 账单透镜 BillLens

> 拖入微信 / 支付宝账单 CSV，10 秒生成消费复盘报告，全程本地，不上传一分钱数据。

## 它解决什么

官方账单只有几百行流水列表：转账、退款也混在支出里，看不出钱到底花在哪。用表格透视要折腾半小时，把账单传到在线工具又怕隐私泄露。

BillLens 只做一件事：把流水变成能看懂、能分享的月报。打开就是用，不用装、不用注册、不用联网传数据。

## 功能

- 自动识别微信、支付宝导出的 CSV，处理中文编码（UTF-8 / GBK）和表头说明行
- 自动剔除转账、退款、信用卡还款，避免支出被重复计算
- 按关键词自动分类：餐饮、交通、购物、订阅等，分类可改，规则保存在本地
- 一屏看清：月度趋势、分类占比、商家 Top 10、最大一笔消费
- 一键生成脱敏报告图：可隐藏金额和商家名，放心发朋友圈或小红书
- 单文件运行，无账号、无服务器，关掉页面数据即消失

## 快速开始

1. 在微信支付 / 支付宝里导出近三个月账单 CSV
   - 微信：我 → 服务 → 钱包 → 账单 → 右上角 … → 账单下载
   - 支付宝：我的 → 账单 → 右上角 … → 开具交易流水证明 / 导出明细
2. 下载 `index.html`，双击用浏览器打开
3. 把 CSV 拖进页面，即刻查看报告

不想先导自己的账单？点「先试试示例数据」，内置了一份虚构的 11 月流水；`examples/` 目录里还有两份微信、支付宝格式的示例文件，可以直接拖进去试。

## 常见问题

**导出的文件是 xlsx 不是 csv？**
微信账单默认导出 xlsx，在表格软件里另存为 CSV 再拖进来即可；支付宝直接导出 CSV。

**打开页面图表是空白？**
图表用 ECharts 的 CDN 加载，第一次打开需要联网；离线时会自动改用简易条形图，数字不受影响。

**分类分错了怎么办？**
在流水明细里点分类下拉改掉，同一家店以后都会按你改的算，只存在你的浏览器里。

**我的账单数据会去哪？**
哪也不去。文件在浏览器本地解析，不经过任何服务器，刷新或关闭页面就清空。
